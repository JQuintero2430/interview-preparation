- Key claims: Java 25 class files have major version 69 [Doc: JVMS 25 §4.1] and R2 `M01 §1 · Java 25 class file major version is 69`, `M01 §1 · --release 21 emits major version 65`; source-file mode [Doc: JEP 330 (Java 11), JEP 458 multi-file (Java 22)]; instance `main` and compact source files final in Java 25 [Doc: JEP 512, verify in the task]; launch selection rules [Doc: JLS 25 §12.1.4]. - Key claims: [Doc: JLS 25 §4.2 (ranges), §5.1.2–5.1.3 (widening, narrowing), §5.6 (promotion), §15.17.2–15.17.3 (division, remainder)]; R1 `M01 §2 · int overflow wraps`, `M01 §2 · addExact throws on overflow`, `M01 §2 · 0.1 + 0.2 is not 0.3 in double`, `M01 §2 · BigDecimal from String is exact`; [Src/Doc: `BigDecimal(double)` Javadoc].

### §3. Lexical structure, operators and control flow · 975 words (850 + 125 from the headroom by SEC-M01-03) · `SEC-M01-03` (M)
