- **F1 (w).** WCAG 2.2 is a "W3C Recommendation 12 December 2024" (`https://www.w3.org/TR/WCAG22/`). SC **2.5.7 Dragging Movements (Level AA)**: "All functionality that uses a dragging movement for operation can be achieved by a single pointer without dragging, unless dragging is essential or the functionality is determined by the user agent and not modified by the author." SC **2.5.8 Target Size (Minimum) (Level AA)**: "The size of the target for pointer inputs is at least 24 by 24 CSS pixels, except when:" (Spacing, Equivalent and further exceptions; quote abridged and say so). SC **2.4.11 Focus Not Obscured (Minimum) (Level AA)**: "When a user interface component receives keyboard focus, the component is not entirely hidden due to author-created content." Owner context: 36 §6 already cites 2.1.1 Keyboard and 2.5.7 for CDK drag and drop (line 623).
