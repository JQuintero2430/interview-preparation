*Compiler (R, `ngc` 22.2.1):*
- F1. `@for` without `track`: `NG5002: @for loop must have a "track" expression`. `track ref` where `ref` is a template variable of an `ng-template`: `NG8009: Cannot access 'ref' inside of a track expression. Only 'item', '$index' and properties on the containing component are available to this expression.` An uninvoked track function (`track trackByName`): warning `NG8115` ("should be invoked: trackByName(/* arguments */)"). `@for` over a number: `TS2488`.
- F2. `@if (user()) { user().name }` with `user: Signal<User | null>`: `TS2531 Object is possibly 'null'`; `@if (user(); as u) { u.name }` compiles. `@if (n() > 1; as big)` aliases the **condition result**. An alias is not visible in `@else`: `TS2339 Property 'u' does not exist`.
- F3. `@default never;` with a plain property: `TS2322 Type '"c"' is not assignable to type 'never'` when a case is missing. With `@switch (sig())` the check gives a **false positive** even when all cases are covered, and `never(sig())` fails the same way; `@let s = sig()` then `@switch (s)` compiles and checks correctly; `@default never(obj)` works for a nested union. Matches the docs NOTE (r, v22.2.1 `control-flow.md`).
- F4. Emitted: `track $index` → `ɵɵrepeaterTrackByIndex`; `track item` → `ɵɵrepeaterTrackByIdentity`; `track item.id` → `($index,$item)=>$item.id`; a component method → a function plus `true` (uses the component instance). `ɵɵrepeaterCreate(index, tmpl, decls, vars, tag, attrs, trackBy, usesCmp, emptyTmpl, …)`. `@if`/`@else if`/`@else`/`@switch` → `ɵɵconditionalCreate` and `ɵɵconditional(index, contextValue)`. `@let` → `ɵɵdeclareLet`, `ɵɵstoreLet`, `ɵɵreadContextLet` (read inside `@defer`, `@for` and `@if` compiles). All `ɵ` names are internal: read for understanding, never recommended (Q12.25).
- F5. Defer diagnostics: `NG8019` (viewport trigger without a placeholder), `NG8020` (placeholder needs exactly one root element), `NG8010` (trigger reference not found), warning `NG8021` (`immediate` with other triggers; a prefetch timer not earlier than the main one; `prefetch` without a main trigger; `when` plus `prefetch when` with the same condition). `*ngIf` without an import: warning `NG8103`.
- F6. Defer emit: `ɵɵdefer(index, primary, DepsFn, loading, placeholder, error, loadingCfg, placeholderCfg, ɵɵdeferEnableTimerScheduling)`; `consts [[1000,100],[500]]` holds `@loading` minimum/after and `@placeholder` minimum. A defer-only standalone dependency emits `import("./heavy").then(m => m.Heavy)`; a dependency also used outside `@defer`, or referenced by `viewChild(Heavy)`, emits `() => [Heavy]` (eager) and keeps its import. No `on` trigger adds an implicit `ɵɵdeferOnIdle()`. Dev mode emits `ɵsetClassMetadataAsync`.

*Runtime (R, `ng test`, jsdom):*
- F7. Truthiness: `[]`, `'0'` and `{}` are truthy; `0`, `''`, `null`, `NaN`, `undefined` are falsy. Changing an `as` alias value (non-null to another non-null) keeps the branch view (child constructor count 1); null destroys it and a return recreates it (count 2).
- F8. `@for`: `track x.id` with new objects reuses the DOM nodes after a reorder; `track x` (identity) with new objects recreates all nodes and warns `NG0956` through `console.warn` ("caused re-creation of the entire collection of size 3", needs rows with more than 2 slots); the same objects reordered under identity tracking reuse nodes; `track $index` keeps nodes at their positions, so unbound DOM state (a typed input value) sticks to the position. `$count`, `$first`, `$last`, `$even`, `$odd`, `$index` work; nested aliases (`let i = $index`) work. `@for` accepts arrays, `Set`, `Map` (items are `[k, v]`), strings (by code point) and generators; `null` and `undefined` render nothing with no error. `NG0955` (duplicate key) is warned only on update, not on first render (text starts `key "a" at index "0" and "2", …`).
- F9. `@switch` uses `===`; the first matching case wins; no fallthrough; no match and no `@default` renders nothing.
- F10. View reuse (the docs' breaking change): an in-place id change under `@for … track x.id` keeps the row (constructor count 2 with the binding updated); `*ngFor` with `trackBy` recreates it (count 3).
- F11. Defer under jsdom: the default `deferBlockBehavior` is Playthrough (runtime constant `DEFER_BLOCK_DEFAULT_BEHAVIOR = DeferBlockBehavior.Playthrough`, and the docs say playthrough). The typings comment says "Defaults to `manual`": a stale contradiction (open point, C7). `on idle` fires in about 10 ms through the `setTimeout` fallback (no `requestIdleCallback` in jsdom). `on hover` fires on `mouseover`, `on interaction` on `click` (on the placeholder), `on viewport` with the stubbed observer (observe called once; options `undefined` when none given), `on timer(100ms)` shows the placeholder until about 110 ms. `when` is one-shot: stays Complete after the condition turns false. `prefetch when` evaluated the fixture module (a top-level log) while the placeholder was still shown.
- F12. Errors: a fixture that throws at evaluation renders `@error`. With no `@error`: `NG0750: Loading dependencies for \`@defer\` block failed, but no \`@error\` block was configured (used in the '_G1' component template). …` goes to `ErrorHandler` (with `rethrowApplicationErrors: false`).
- F13. Manual mode: the idle trigger does not fire; `fixture.getDeferBlocks()` returns the blocks; `render(DeferBlockState.Complete)` renders the content.
- F14. Timing (real timers, a top-level-await fixture to make loads slow): a 120 ms load with `@loading (after 40ms; minimum 100ms)` under `on immediate` shows nothing until 40 ms, then the loading block at 40 ms, then the content at about 150 ms (the minimum holds the loading block). A 20 ms load with `after 60ms` never shows the loading block (content at about 30 ms). `@placeholder (minimum 80ms)` holds the placeholder until about 80 ms with the default idle trigger. With `on immediate` the placeholder is rendered only if there is no `@loading` block (read, `ɵɵdeferOnImmediate`), so `minimum` on `@placeholder` has no effect when a `@loading` block exists (observed).

### 1. Built-in blocks versus directives, and the `@if` family with `as` · ~850 words · SEC-M18-01
- **Problem:** a template shows a panel only when data exists, with a fallback, and then reads the data inside; `*ngIf` needs an import and an `ng-template` for `else`; a developer asks why the same `@if (user())` does not narrow the signal inside; an interviewer asks what is truthy.
- **Model:** the blocks are template syntax the compiler understands, not directives; each branch is an embedded view created and destroyed with its condition. Analogy: a railway switch that sends the train down one track and leaves the other tracks empty. Diagram: `flowchart TD` of `@if (c1) → block 1`, `@else if (c2) → block 2`, `@else → block 3` with the condition evaluated once per update and a dashed arrow to `as alias` available only in the matched branch. **What to notice:** one branch is alive at a time, and the alias exists only inside the branch that matched.
- **Mechanism:** compiled to `ɵɵconditional` with a branch index (F4); truthiness is JavaScript's (F7); `as` aliases the **condition result** and narrows the expression (F2); the alias is not visible in `@else` (F2); a change of alias value keeps the branch view, null destroys it (F7); `@else if … as` since 20.2.0 (F20); built-in control flow is `[Stable since v18.0]` (C2); `*ngIf` without an import warns `NG8103` (F5); `*ngIf`/`*ngFor`/`*ngSwitch` deprecation per VERSIONS (the marker `[Deprecated since v20 — use @if, @for and @switch]` is in the form modules 13 and 14 use). Read from the 22.2.1 source: how `ɵɵconditional` picks the branch template and when it creates or destroys the view (§9 goes deeper, link, do not repeat).
- **First-use definitions:** control flow block, embedded view, truthy/falsy (link [Q01.17](../../modules/01-js-values-types-coercion.md#q01-17)), alias (`as`), narrowing (link [06](../../modules/06-ts-type-system-essentials.md)), signal (link [17](../../modules/17-signals.md)), `strictTemplates` (link 13), AOT (link [Q12.19](../../modules/12-angular-how-it-works.md#q12-19)), OnPush (link 21).
