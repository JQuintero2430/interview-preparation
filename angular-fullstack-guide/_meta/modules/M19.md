- F17. `matchingProjectionSlotIndex(tNode, projectionSlots)`: walks the slot selectors in order, remembers the index of `'*'` as the wildcard, returns the **first** slot whose selector list matches the node (or, when the node has an `ngProjectAs` value, whose list contains that selector), else the wildcard index, else `null` (the node is not projected anywhere). `ɵɵprojectionDef(slots)` runs **once per component host node** (`componentNode.projection` is cached) and chains the host's child nodes (skipping `TNodeType` 128, a `@let`) into per-slot linked lists (`projectionNext`). `ɵɵprojection(nodeIndex, selectorIndex, attrs, fallbackFn, …)` computes `isEmpty = componentHostNode.projection[slot] === null` and calls `insertFallbackContent` when empty and a fallback exists, else `applyProjection`; **emptiness is "no node matched the slot", not "nothing rendered"**, which explains F7's `@if (false)` result. - F18. Queries. `ɵɵcontentQuery(directiveIndex, predicate, flags, read)` and `ɵɵviewQuery(predicate, flags, read)` create a `TQuery` once per `TView` (`createContentQuery`, `createViewQuery`); the flags are bit flags where `1` is descendants, `2` is static and `4` is `emitDistinctChangesOnly` (the F5 numbers `4` and `5`; the bit meaning is read from `createViewQuery` using `(flags & 2) === 2` for static, and `ɵɵqueryRefresh` testing `isCreationMode(lView) === ((tQuery.metadata.flags & 2) === 2)`, so a **static** query refreshes in creation mode and a dynamic one in update mode; **confirm the bit-to-name map in SEC-M19-05 from the typings or `QueryFlags` before writing it**). A signal query is `createQuerySignalFn(firstOnly, required, opts)`: a `computed` that reads `node._dirtyCounter()`, calls `refreshSignalQuery` (`queryList.reset(getQueryResults(...))`, returns `queryList.first` or the cached array when nothing changed) and, for `required`, throws `RuntimeError(-951, 'Child query result is required but no value is available.')`; `bindQueryToSignal` registers `queryList.onDirty(() => node._dirtyCounter.update(v => v + 1))`; a destroyed `LView` (flag 4) gives `undefined` or an empty array. The generated update block calls `ɵɵqueryAdvance()` for a signal query (it only moves the query index) and `ɵɵqueryRefresh` for a decorator query (it resets the `QueryList` and returns whether it changed, so the field assignment runs).
- F19. `listenToOutput(tNode, lView, directiveIndex, lookupName, eventName, listenerFn)` reads the instance's output property and calls `output.subscribe(listenerFn)` **after** the directive instance exists (it throws in dev mode if the property is not subscribable, `@Output … not initialized`), which is why an emit in the constructor reaches nobody. `OutputEmitterRef` (`_resource-chunk.mjs`) keeps a `listeners` array, no buffer. `ngOnChangesSetInput` (the `ɵɵNgOnChangesFeature` path for signal inputs) records a `SimpleChange` per input into the same store as decorator inputs, then applies the value, which is why `ngOnChanges` fires for signal inputs.
