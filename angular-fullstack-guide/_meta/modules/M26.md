### 1. Why a third forms API: model-first, signals end to end · delta 900 (800 + 100 verification paragraph) · SEC-M26-01
- **Problem:** a profile editor keeps the data in a signal for the rest of the page but copies it into a `FormGroup`, then copies it back on save; the two drift (an external update to the signal never reaches the form, a typed value never reaches the signal until submit); validity lives in Observables next to signals; a new hire asks which API to use.
- **Model:** the **model signal is the form**: `form(model)` wraps a writable signal you own and returns a field tree whose values are views onto that signal (F6); validation is declared once, as rules on paths of the model (the schema), and every piece of state (value, errors, touched, pending) is a signal the template reads. Analogy: reactive forms keep a duplicate ledger that you reconcile; Signal Forms annotate the original ledger in the margin. Diagram: `flowchart LR`: `"model: WritableSignal"` ↔ `"field tree (form())"` ↔ `"[formField]"` ↔ `"input"`, with `"schema rules"` feeding the field tree, and a second, smaller lane for reactive forms: `"component data"` → copy → `"FormGroup"` → copy back. **What to notice:** the Signal Forms lane has one copy of the data, the reactive lane two.
- **Mechanism:** F5 (the docs comparison table rows, quoted with path, branch `main` and date; the overview's "work best in new applications" sentence); F6 at the architecture level (no own copy; one sentence, forward link §2); F2/F3 (stable public API since 22.0, experimental in 21: CHANGELOG line and typings tags); the three entry points of F1; **read from the `@angular/forms` 22.2.1 source**: the `form` typings doc sentence "does not maintain its own copy of the data" (`types/_structure-chunk.d.ts`) and `deepSignal` (internal) as the reason a field write is a model write (one sentence; §2 owns it). The two older APIs are [25 §1](../../modules/25-forms-reactive-and-template-driven.md#1-two-forms-apis-template-driven-and-reactive-and-the-control-directive-and-accessor-triangle) (one sentence); the choice among the three is [Q25.02](../../modules/25-forms-reactive-and-template-driven.md#q25-02) (one sentence).
